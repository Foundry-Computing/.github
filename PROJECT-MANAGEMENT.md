# Project Management

## Source of truth

GitHub Issues are the source of truth for significant work. The Foundry
Development project is the portfolio-level coordination surface for planned,
active, blocked, and review-stage work.

## Intended workflow

Preferred lifecycle:

`Backlog -> Planned -> Active -> In Review -> Blocked -> Version 1.0 Complete`

## Expected fields

The intended project field set includes:

- Status
- Priority
- Repository
- Product
- Epic
- Phase
- Work Type
- Estimated Effort
- Completion Gate
- AI Owner
- Review Required
- Target Date

## Expected views

The intended view set includes:

- Mission Control
- Portfolio
- Roadmap
- Active Work
- AI Workload
- Needs Review
- Blocked by Repository
- Phase 2
- Version 1.0 Gates
- Backlog

## Operational guidance

- Avoid duplicate issues, implementations, and project items.
- Keep status, ownership, dependencies, and completion gate current.
- Attach validation evidence and completion notes to the linked issue or PR.
- Use `Blocked` when progress cannot continue without a dependency or approval.
