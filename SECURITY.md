# Security Policy

Do not disclose credentials, private infrastructure details, personal data, or
unpatched vulnerabilities in public issues.

For repositories with GitHub private vulnerability reporting enabled, use the
repository's **Security** tab. Otherwise contact an organization owner through
an established private channel. Do not send secrets as evidence.

Reports should identify the affected repository and version, describe impact
and reproduction with minimized data, and suggest containment where known.

Authentication, authorization, secret handling, destructive operations, and
network exposure require explicit security review.
