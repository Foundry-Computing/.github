# Contributing

Start with an existing GitHub issue or open one before significant work. Check
the Foundry Development project to avoid duplicating active or planned work.

Keep changes focused, preserve repository-specific architecture boundaries,
and include tests and validation evidence appropriate to the change. Link
architecture decisions or ADRs when behavior or ownership boundaries change.

Repository-specific contribution and security instructions take precedence.
Private or internal repositories may use a different review workflow and are
not made public by this document.
